# 系統使用說明

## 這個系統是什麼

自主採購代理人是一個以自然語言驅動的採購系統。您不需要填寫表單或記住固定格式，只需要用日常語言描述需求，系統會自動完成查價、合規審核與下單。

## 如何使用

### 基本操作

1. 在畫面下方的輸入框輸入採購需求
2. 系統會自動查詢商品價格
3. 若金額符合預算，直接下單
4. 若超出預算，系統會自動調整數量並重新下單

### 輸入範例

- 「我要買 3 個滑鼠」
- 「幫部門採購 5 個鍵盤，預算大概兩千左右」
- 「我需要一些辦公文具，紙和筆各買一些」
- 「採購規範裡，買螢幕需要什麼流程？」
- 「目錄裡有哪些鍵盤可以選？」

### 設定預算

畫面左側 Sidebar 可以調整本次採購的預算上限，系統不會下單超過此金額的訂單。

## 常見問題

**Q：系統支援哪些商品？**
A：請參考商品目錄，目錄以外的商品請聯繫採購部門詢價。

**Q：下單後可以取消嗎？**
A：目前系統尚未支援取消功能，如需取消請直接聯繫採購部門。

**Q：超出預算時系統會怎麼做？**
A：系統會自動計算在預算內最多可購買的數量，並以修正後的數量重新下單，不需要人工介入。

**Q：如何查詢採購規範？**
A：直接在對話框詢問，例如「買筆電需要什麼流程？」，系統會查詢規範後回答。
